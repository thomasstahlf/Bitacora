# Bitácora - Introducción a Ciencia de Datos

Apuntes de clase y cuaderno personal del curso **Introducción a la Ciencia de Datos**.

## Estructura del repositorio

- **data/** - Conjuntos de datos
  - `raw/` - Datos originales sin procesar
  - `processed/` - Datos limpios y procesados
  
- **Scripts/** - Código Python reutilizable
  - Scripts de limpieza, análisis y transformación de datos
  - Se ejecutan desde terminal: `python script.py`

- **Notebooks/** - Jupyter Notebooks interactivos
  - Exploración de datos y visualizaciones
  - Análisis paso a paso con resultados inmediatos

- **Documentos Word-PDF/** - Apuntes y resúmenes
  - Apuntes de clase
  - Resúmenes de temas
  - Documentación

## Cómo usar este repositorio

1. Clona el repo: `git clone https://github.com/thomastahlf/Bitacora.git`
2. Explora los notebooks en `Notebooks/` para aprender
3. Usa los scripts en `Scripts/` como referencia
